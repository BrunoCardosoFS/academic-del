# 1. Introdução — O que é o academic-del?

O **academic-del** é um conjunto de templates acadêmicos (Trabalhos de Conclusão de Curso — TCC e Relatórios Finais de Iniciação Científica — PIBIC/PICVOL) escritos em **Typst**, desenvolvidos especificamente para atender às normas da **ABNT** e às diretrizes do **Departamento de Engenharia Elétrica (DEL) da Universidade Federal de Sergipe (UFS)**.

---

## O que é o Typst?

[Typst](https://typst.app) é uma linguagem de marcação moderna para criação de documentos acadêmicos e científicos. É uma alternativa ao LaTeX com as seguintes vantagens:

- **Compilação instantânea** — feedback em tempo real durante a edição.
- **Sintaxe simples e legível** — muito mais fácil de aprender que LaTeX.
- **Mensagens de erro claras** — sabe exatamente o que deu errado e onde.
- **Ambiente web integrado** — funciona diretamente no navegador em [typst.app](https://typst.app).
- **Extensível** — permite criar templates e funções personalizadas.

---

## Por que usar este template?

Escrever um TCC no Word ou LibreOffice pode ser um pesadelo de formatação: margens, recuos, numeração de páginas, listas de figuras e tabelas geradas manualmente, estilos inconsistentes, etc.

O **academic-del** automatiza tudo isso:

| O template faz por você | Você só precisa fazer |
|---|---|
| Margem ABNT (30/30/20/20 mm) | Preencher os dados do trabalho |
| Numeração de páginas correta | Escrever o conteúdo |
| Geração automática do Sumário | Inserir figuras com `#figura(...)` |
| Lista de Figuras e Tabelas | Usar `#sigla(...)` para abreviaturas |
| Lista de Abreviaturas e Siglas | Citar referências com `@chave` |
| Folha de Rosto e Aprovação | Incluir a `.bib` com as referências |
| Formatação tipográfica ABNT | — |
| Espaçamento entre seções | — |
